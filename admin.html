Security Architecture Disclosure:

This website is a 100% static, client-side application engineered to cost ₹0 to host on free hosting tiers (Netlify, Vercel, GitHub Pages). Authentication is enforced locally via the browser's localStorage API.

While this is ideal for managing your personal portfolio without paying for database servers, it is not a replacement for server-side enterprise security. Do not store sensitive secrets, financial keys, or production credentials in this static system.
